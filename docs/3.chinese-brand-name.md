# MateClaw 中文命名方案

## 推荐名称

**御枢**

英文并列写法：

**御枢 MateClaw**

推荐副标题：

**企业 AI 数字员工中枢**

一句话定位：

**把模型、知识、工具、工作流和审批审计统一调度起来的企业级 AI 中枢。**

## 命名结论

MateClaw 的中文名建议主打 **御枢**。

这个名字更贴合项目当前的产品重心：MateClaw 不是一个单用户聊天助手，也不只是一个模型调用壳，而是一套面向团队和企业部署的 AI 工作系统。它把数字员工、模型供应商、知识 Wiki、工具权限、MCP/ACP、工作流、触发器、IM 渠道、运行时监控和审计审批收敛在同一个管理面里。

因此中文名需要表达两个核心感受：

- **可调度**：所有能力围绕一个中枢组织和运行。
- **可治理**：企业可以管控权限、审批敏感动作、追踪审计日志、私有化部署。

**御枢** 同时覆盖这两层含义。

## 字义拆解

### 御

“御”有驾驭、统御、控制、护持的含义。

它对应 MateClaw 的企业级能力：

- 多模型供应商健康检测与故障转移
- RBAC 权限控制
- Tool Guard 工具边界
- 敏感操作审批
- 审计事件流
- 运行时控制台
- 私有化部署和数据不出门

“御”让名字带有控制力和可信赖感，不会显得只是一个轻量聊天应用。

### 枢

“枢”是中枢、枢纽、关键节点。

它对应 MateClaw 的系统结构：

- 数字员工统一管理
- 知识库与记忆系统
- 技能、MCP、ACP、插件 SDK
- 工作流与触发器
- Web 控制台、桌面端、嵌入式聊天、IM 渠道
- 多模态和文档生成工具

“枢”强调 MateClaw 是一个 AI 能力组织层，而不是单点工具。

## 为什么不主推“太一”

当前 README_zh 中已经出现 **太一（MateClaw）**。这个名字有很强的东方意象，适合作为内部代号、版本名、模型名或品牌故事的一部分，但不建议作为主中文名。

主要原因：

- **语义偏宏大**：太一更像哲学概念或底层大模型名，不够直接传达企业 AI 中枢。
- **产品指向弱**：用户第一次看到“太一”时，很难立刻联想到数字员工、工作流、审批、审计、多模型调度。
- **检索混淆风险更高**：太一相关命名在 AI、云服务、模型和传统文化语境中都较常见，品牌独占感不强。

建议处理方式：

```text
御枢 MateClaw，代号“太一”
```

或者在品牌故事中保留：

```text
太一，是御枢最初的内部代号，寓意把分散的 AI 能力归于一体。
```

## 视觉气质建议

现有 MateClaw logo 是暖金、铜色、环形结构，视觉上像一个旋转的护环或中枢结构，与“御枢”的命名方向是兼容的。

后续中文品牌视觉可以强化：

- **中枢感**：环形、轨道、节点、连接
- **治理感**：秩序、边界、权限、审计线索
- **企业感**：低噪声、清晰层级、可靠运维
- **数字员工感**：角色、协作、任务执行状态

不建议把视觉过度做成传统国风或玄学风格。“御枢”的优势不是古风，而是“可控的 AI 中枢”。
