# 1.接口约定
1. 首页接口约定
- 首页接口使用移动端聚合接口 `GET /api/v1/mobile/home`
- 登录后调用，默认需要携带 `Authorization: Bearer <token>`
- 首页聚合接口必须携带当前工作空间 `X-Workspace-Id`，移动端需先调用 `GET /api/mobile/user/workspaces` 获取工作空间列表和默认工作空间 ID
- 所有接口响应统一遵守 `R<T>` 包裹格式
- 首页接口用于减少移动端首屏请求次数，后端内部聚合 Dashboard、模型、系统健康和最近运行等现有接口数据

|参数名|参数类型|是否必填|备注|
|---|---|---|---|
|code|整数|是|状态码，成功时为 `200`|
|msg|字符串|是|提示信息|
|data|对象/空|是|业务数据，失败时可为空|

# 2.首页相关
## 2.1 获取当前用户基本信息接口
```http request
GET /api/mobile/user/profile
Authorization: Bearer <token>
```

接口用途：
```text
移动端登录成功后可调用本接口获取当前用户基本信息，用于首页头像、昵称、角色展示，以及本地用户状态恢复。
本接口只返回可展示的用户字段，不返回密码、密钥等敏感信息。
```

请求参数：

|参数名|参数类型|是否必填|参数位置|备注|
|---|---|---|---|---|
|Authorization|字符串|是|header|登录接口返回的 JWT，格式为 `Bearer <token>`|

请求参数示例：
```http request
GET /api/mobile/user/profile
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
```

响应值：

`data` 字段说明：

|参数名|参数类型|是否必填|备注|
|---|---|---|---|
|id|整数|是|用户 ID|
|username|字符串|是|用户名|
|nickname|字符串|是|昵称|
|avatar|字符串/空|否|头像 URL|
|email|字符串/空|否|邮箱|
|role|字符串|是|全局角色，`admin` / `user`|
|enabled|布尔|是|账号是否启用|

响应值示例：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "id": 1001,
    "username": "demo",
    "nickname": "小明",
    "avatar": "https://example.com/avatar.png",
    "email": "demo@example.com",
    "role": "user",
    "enabled": true
  }
}
```

接口逻辑：
```text
1. 校验 Authorization，未登录返回 401
2. 根据 token 中的用户名或用户 ID 查询用户
3. 如果用户不存在、被删除或被禁用，返回 401
4. 返回用户基础展示信息，不返回 password 等敏感字段
```

异常返回：

|HTTP 状态|code|msg|触发场景|
|---|---|---|---|
|401|401|authentication required|未登录、token 无效、用户不存在或账号已禁用|
|500|500|系统异常|查询用户信息失败|

## 2.2 获取当前用户工作空间列表接口
```http request
GET /api/mobile/user/workspaces
Authorization: Bearer <token>
```

接口用途：
```text
登录接口只返回用户基础信息和 JWT，后续首页等业务接口需要 X-Workspace-Id。
移动端登录成功后应先调用本接口，获取当前用户可访问的工作空间列表，并缓存 data.defaultWorkspaceId 作为默认请求头 X-Workspace-Id。
如果用户后续切换工作空间，则使用选中工作空间的 id 覆盖 X-Workspace-Id。
```

请求参数：

|参数名|参数类型|是否必填|参数位置|备注|
|---|---|---|---|---|
|Authorization|字符串|是|header|登录接口返回的 JWT，格式为 `Bearer <token>`|

请求参数示例：
```http request
GET /api/mobile/user/workspaces
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
```

响应值：

`data` 字段说明：

|参数名|参数类型|是否必填|备注|
|---|---|---|---|
|defaultWorkspaceId|整数|是|当前用户默认工作空间 ID，后续默认作为 `X-Workspace-Id` 请求头|
|workspaces|数组|是|当前用户可访问的工作空间列表|

`workspaces` 数组元素字段说明：

|参数名|参数类型|是否必填|备注|
|---|---|---|---|
|id|整数|是|工作空间 ID|
|name|字符串|是|工作空间名称|
|slug|字符串|是|工作空间标识|
|role|字符串|是|当前用户在该工作空间的角色，例如 `owner` / `admin` / `member` / `viewer`|
|isDefault|布尔|是|是否为当前用户默认工作空间|
|memberCount|整数|是|当前工作空间成员数量|
|roleCount|整数|是|当前工作空间角色数量|
|agentCount|整数|是|当前工作空间 Agent 数量|

响应值示例：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "defaultWorkspaceId": 2001,
    "workspaces": [
      {
        "id": 2001,
        "name": "小明的工作台",
        "slug": "demo-1001",
        "role": "owner",
        "isDefault": true,
        "memberCount": 3,
        "roleCount": 4,
        "agentCount": 8
      },
      {
        "id": 2002,
        "name": "项目协作空间",
        "slug": "project-team",
        "role": "member",
        "isDefault": false,
        "memberCount": 12,
        "roleCount": 4,
        "agentCount": 21
      }
    ]
  }
}
```

接口逻辑：
```text
1. 校验 Authorization，未登录返回 401
2. 根据 token 中的用户身份查询当前用户可访问的工作空间列表
3. 按用户默认工作空间配置、最近使用工作空间或创建时间确定 defaultWorkspaceId
4. 查询每个工作空间的成员数、角色数量和 Agent 数量
5. 如果用户没有可访问工作空间，返回 404
6. 返回工作空间列表和 defaultWorkspaceId，移动端缓存 defaultWorkspaceId
7. 后续首页接口和其他业务接口默认携带 X-Workspace-Id = data.defaultWorkspaceId
```

异常返回：

|HTTP 状态|code|msg|触发场景|
|---|---|---|---|
|401|401|authentication required|未登录或 token 无效|
|404|404|工作空间不存在|当前用户未绑定可用工作空间|
|500|500|系统异常|查询工作空间失败|

## 2.3 首页聚合接口
```http request
GET /api/v1/mobile/home?recentRunLimit=5
Authorization: Bearer <token>
X-Workspace-Id: 2001
```

请求参数：

|参数名|参数类型|是否必填|参数位置|备注|
|---|---|---|---|---|
|Authorization|字符串|是|header|登录接口返回的 JWT，格式为 `Bearer <token>`|
|X-Workspace-Id|整数|是|header|默认或当前选中的工作空间 ID|
|recentRunLimit|整数|否|query|最近运行条数，默认 `5`，建议最大不超过 `20`|

请求参数示例：
```http request
GET /api/v1/mobile/home?recentRunLimit=5
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
X-Workspace-Id: 2001
```

响应值：

`data` 字段说明：

|参数名|参数类型|是否必填|备注|
|---|---|---|---|
|currentModel|对象/空|是|顶部当前模型卡片；没有可用模型时为空|
|todayCard|对象|是|今日会话主卡片|
|periods|数组|是|周期对比卡片，固定返回今日、本周、本月|
|recentRuns|数组|是|最近运行列表|

`currentModel` 字段说明：

|参数名|参数类型|是否必填|备注|
|---|---|---|---|
|providerId|字符串|是|Provider 标识，例如 `openai`|
|providerName|字符串|是|Provider 展示名称，例如 `OpenAI`|
|model|字符串|是|模型名称，例如 `gpt-4.1`|
|status|字符串|是|模型状态：`ready` / `warning` / `error` / `unknown`|
|statusText|字符串|是|模型状态展示文案，例如 `Ready`|

`todayCard` 字段说明：

|参数名|参数类型|是否必填|备注|
|---|---|---|---|
|conversations|整数|是|今日会话数，主数字展示|
|messages|整数|是|今日消息数|
|toolCalls|整数|是|今日工具调用次数|
|healthStatus|字符串|是|系统健康状态：`healthy` / `warning` / `error` / `unknown`|
|healthText|字符串|是|健康状态展示文案，例如 `健康`|

`periods` 数组元素字段说明：

|参数名|参数类型|是否必填|备注|
|---|---|---|---|
|key|字符串|是|周期标识：`today` / `thisWeek` / `thisMonth`|
|title|字符串|是|周期标题：`今日` / `本周` / `本月`|
|conversations|整数|是|周期内对话数|
|messages|整数|是|周期内消息数|
|totalTokens|整数|是|周期内总 Token 数|
|toolCalls|整数|是|周期内工具调用次数|

`recentRuns` 数组元素字段说明：

|参数名|参数类型|是否必填|备注|
|---|---|---|---|
|id|整数|是|运行记录 ID|
|cronJobId|整数|否|定时任务 ID|
|title|字符串|是|任务展示名称|
|status|字符串|是|运行状态：`running` / `success` / `failed`|
|statusText|字符串|是|运行状态展示文案，例如 `成功` / `运行中` / `失败`|
|startedAt|字符串|否|开始时间，ISO 8601 格式|
|timeText|字符串|否|相对时间展示文案，例如 `2分钟前`|
|tokenText|字符串|否|Token 消耗展示文案，例如 `12.4k tokens`|
|detailText|字符串|否|补充信息，例如 `飞书渠道 · 3 步骤`|

接口逻辑：
```text
1. 校验 Authorization，未登录返回 401
2. 校验 X-Workspace-Id，确认当前用户拥有该工作空间访问权限；无权限返回 403
3. 调用 Dashboard 统计能力，取得 today、thisWeek、thisMonth
4. 调用模型能力取得当前默认模型，并补充 providerName 和状态文案
5. 调用系统健康能力取得 overall，只返回首页健康徽标需要的状态和文案
6. 调用 Dashboard 最近运行能力，按 recentRunLimit 取得最近运行记录，并转成首页列表展示字段
7. 组装首页聚合响应并返回
```

数据来源：

|数据块|后端来源|备注|
|---|---|---|
|todayCard / periods|`GET /api/v1/dashboard/overview`|现有接口返回 today、thisWeek、thisMonth|
|currentModel|`GET /api/v1/models/active`、`GET /api/v1/models`|只返回当前模型卡片需要的字段|
|todayCard.healthStatus|`GET /api/v1/system/health`|只使用 overall|
|recentRuns|`GET /api/v1/dashboard/cron-runs?limit=5`|聚合层建议补充任务名称|

异常返回：

|HTTP 状态|code|msg|触发场景|
|---|---|---|---|
|401|401|authentication required|未登录或 token 无效|
|403|403|无权访问当前工作空间|用户不属于 `X-Workspace-Id` 对应工作空间|
|400|400|参数错误|`recentRunLimit` 超出允许范围|
|500|500|系统异常|聚合依赖接口异常且无法降级|

降级规则：
```text
1. Dashboard 统计失败时，首页接口整体失败，避免移动端展示错误的核心数据
2. 当前模型查询失败时，currentModel 返回 null
3. 系统健康查询失败时，todayCard.healthStatus 返回 unknown，healthText 返回 未知
4. 最近运行失败时，recentRuns 返回空数组
```
